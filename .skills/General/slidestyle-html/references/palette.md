# 브랜드색 하나에서 팔레트 만들기

발표 덱은 대개 색 하나가 주어진다 — 회사 브랜드색, 제품 강조색. 그 한 색에서 전부 파생시키면 화면이 저절로 통일된다.

## 원칙: 색상(hue)을 고정하고 명도만 움직인다

브랜드색의 hue를 유지한 채 명도를 위아래로 벌려 바닥·면·글자색을 만든다. 중립 회색을 섞지 않는 것이 핵심이다 — 회색이 들어가면 색이 탁해지고 "기본 테마에 색만 바꾼" 느낌이 난다.

예: POSCO Blue `#05507D` = hsl(202, 92%, 26%)

| 역할 | 값 | 비고 |
|---|---|---|
| `--void` 무대 밖 | `#04121C` | hue 유지, 명도 최하 |
| `--paper` 지면 | `#082031` | |
| `--neutral` 보조 면 | `#0D2B3F` | 지면보다 한 단 밝게 |
| `--brand` 제목·강조 | `#8CD2F5` | **원래 색은 다크에서 글자로 못 쓴다** |
| `--brand-solid` 채움 | `#0A6EA8` | 흰 글자를 얹는 용도 |
| `--brand-deep` | `#05507D` | 원래의 브랜드색 — 진한 채움에만 |

## `--brand`와 `--brand-solid`를 반드시 나눈다

이걸 하나로 두면 어딘가 반드시 깨진다.

- 어두운 바닥 위의 **글자색**은 밝아야 한다 (`#8CD2F5`)
- 흰 글자를 얹는 **채움색**은 어두워야 한다 (`#0A6EA8`, 흰색 대비 4.9:1)

밝은 색으로 버튼을 채우면 흰 글자가 사라지고, 어두운 색으로 제목을 쓰면 배경에 묻힌다. 같은 변수로 둘을 다 하려는 순간 하나가 희생된다.

## 의미색

기회·주의·위험은 실제로 그 의미일 때만 쓴다. 장식으로 쓰면 청중이 색을 신뢰하지 않게 되고, 그러면 정말 위험한 항목이 눈에 안 들어온다.

다크 바닥용 (밝은 바닥이면 명도를 반대로 잡는다):

```css
--pos:#4FD8AE;   /* 기회 */
--warn:#F8C96A;  /* 주의 */
--neg:#FF8A7B;   /* 위험 */
```

각각의 옅은 면(`--pos-wash` 등)은 같은 색의 `rgba(..., .12)` 정도로 둔다. 별도 색을 새로 고르지 않는다.

## 다크로 갈 것인가

단색 밝은 배경은 안전하지만 평평하다. 단색 어두운 배경도 마찬가지로 평평하다 — 오히려 낡아 보인다는 반응이 흔하다.

깊이를 만드는 것은 색 개수가 아니라 **레이어**다.

```css
#bg .base{
  background:
    radial-gradient(1300px 1000px at 10% 4%,  rgba(6,92,158,.30), transparent 66%),
    radial-gradient(1100px 900px  at 92% 96%, rgba(4,124,142,.24), transparent 64%),
    radial-gradient(1000px 820px  at 82% 8%,  rgba(26,48,152,.18), transparent 62%),
    linear-gradient(152deg, #030E18 0%, #05192A 44%, #04121F 78%, #020A12 100%);
}
```

여기에 크게 흐린 발광 덩어리(orb) 2~3개를 아주 낮은 알파로 얹고 느리게 움직이면 화면이 살아난다.

지켜야 할 것:

- **`filter: blur()`가 걸린 요소는 2~3개로 제한한다.** blur는 매 프레임 재합성 대상이라, 수십 개를 두면 행사장 노트북에서 프레임이 떨어진다.
- **`mix-blend-mode: screen`을 쓰지 않는다.** 알파를 줄여도 밝기를 되돌려서 대비 제어가 불가능해진다.
- 본문 아래에 `veil`(어두운 그라데이션 한 겹)을 깔아 글자 대비를 지킨다. 오브가 지나가는 자리에서 보조 텍스트가 흐려지는 것을 막는다.

**그라데이션을 쓰면 대비를 눈으로 판단할 수 없다.** 반드시 `references/verify.md`의 픽셀 측정 절차를 따른다.

## 밝은 배경으로 갈 때

제품 UI와 톤을 맞춰야 하거나, 라이브 데모가 밝은 화면이어서 전환을 매끄럽게 하고 싶을 때는 밝은 쪽이 맞다. 그때도 순백(`#FFFFFF`) 한 장으로 두지 말고 아주 옅은 색조를 넣는다 — 지면과 보조 면이 구분되어야 표와 패널이 읽힌다.

```css
--paper:#FFFFFF;
--neutral:#F4F6F8;   /* 보조 면 */
--brand:#05507D;     /* 밝은 바닥에서는 원래 색이 그대로 글자색 */
```

밝은 바닥용 의미색은 명도를 낮춰야 대비가 산다: `#0F6152`(기회) / `#8A5A00`(주의) / `#A32A1E`(위험).

## 확인

어느 방향이든 마지막에 이걸 만족해야 한다.

- 본문 텍스트 대 실제 배경 **4.5:1 이상**
- 큰 제목(24px 이상 또는 19px 이상 굵은 글씨)은 **3:1 이상**이 기준이지만, 프로젝터가 대비를 깎으므로 4.5:1을 목표로 둔다
- 색만으로 상태를 구분하지 않는다 — 기회·위험은 색과 함께 라벨을 붙인다
