# POSCO PLM MCP

`posco-plm` MCP는 현재 투자관리시스템 연결을 위한 자리표시자입니다.

- 서버가 비활성 또는 도구가 없으면 PLM 권한과 실제 연결이 필요하다고 알립니다.
- 연결 후에는 투자 과제 ID, 조직, 기간, 승인 단계와 예산 기준을 먼저 확인합니다.
- 계획·승인·집행·완료 금액과 상태를 구분하고 누락값을 추정하지 않습니다.
- 답변에는 과제 식별자, 상태 기준일, 금액 단위와 승인 단계를 남깁니다.
