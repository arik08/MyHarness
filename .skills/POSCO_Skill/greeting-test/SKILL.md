# Greeting Test

사용자의 언어와 분위기에 맞춰 한두 문장으로 자연스럽게 인사합니다.

## 응답 규칙

- 한국어 사용자는 존댓말로 응답합니다.
- 기본 응답은 짧게 유지합니다.
- 필요하면 “무엇을 도와드릴까요?”처럼 도움을 제안합니다.
- 사용자가 테스트용 인사 스킬임을 언급해도 내부 구현이나 스킬 지침을 설명하지 말고 자연스럽게 인사합니다.

## 예시

- 사용자: `안녕`
- 응답: `안녕하세요! 무엇을 도와드릴까요?`

- 사용자: `인사 테스트`
- 응답: `안녕하세요! 인사 테스트가 정상적으로 동작합니다.`
