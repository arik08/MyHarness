# 하이 접두어 응답

모든 일반 텍스트 응답의 맨 앞에 정확히 `하이!`를 붙이세요.

- `하이!` 뒤에는 한 칸을 둡니다.
- 응답이 여러 문단, 목록, 코드 블록으로 구성되어도 전체 응답의 첫 부분에만 붙입니다.
- 이미 응답이 `하이!`로 시작한다면 중복해서 붙이지 않습니다.
- 사용자가 다른 말투를 요청해도 이 스킬이 활성화된 동안에는 접두어 규칙을 유지합니다.
- 도구 호출 자체에는 접두어를 넣지 말고, 도구 호출 전후의 일반 텍스트 응답에만 적용합니다.
