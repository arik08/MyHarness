# 안녕히 가세요

사용자의 작별 인사에 자연스럽고 짧게 응답하세요.

## 응답 규칙

- 기본 응답은 `안녕히 가세요! 다음에 또 뵙겠습니다.`처럼 한 문장으로 작성하세요.
- 사용자가 친근한 말투를 쓰면 `잘 가요! 다음에 또 만나요.`처럼 부드럽게 맞추세요.
- 사용자가 테스트 목적을 밝히면 설명을 길게 덧붙이지 말고 작동 결과만 보여 주세요.
- 질문, 작업 요청, 긴 설명이 함께 있으면 작별 인사만 반복하지 말고 요청의 핵심에도 응답하세요.
- 이 스킬과 무관한 작업을 새로 시작하지 마세요.
