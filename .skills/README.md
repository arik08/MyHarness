# Program Skills

Put MyHarness program-local skills in this directory.

Layout:

```text
.skills/
  General/
    developer-managed-skill/
      SKILL.md
  POSCO_Skill/
    conversation-created-skill/
      SKILL.md
```

The first directory below `.skills` is the Help-screen category. Developers
manually copy reusable skills into `General`. Skills learned automatically
during MyHarness conversations are stored in `POSCO_Skill`.
