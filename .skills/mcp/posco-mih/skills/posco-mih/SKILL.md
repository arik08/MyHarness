# POSCO MIH MCP

`posco-mih` MCP는 현재 Marketing Information Hub 연결을 위한 자리표시자입니다.

- 서버가 비활성 또는 도구가 없으면 MIH 권한과 실제 연결이 필요하다고 알립니다.
- 연결 후에는 시장·고객·제품·지역·기간과 통화·단위를 먼저 확인합니다.
- 전망, 목표, 실적을 구분하고 서로 다른 기준의 가격을 임의로 비교하지 않습니다.
- 답변에는 자료 또는 지표 식별자, 기준일, 통화와 단위를 남깁니다.
