# POSCO ECM MCP

`posco-ecm` MCP는 현재 사내 ECM 연결을 위한 자리표시자입니다.

- 서버가 비활성 또는 도구가 없으면 ECM 권한과 실제 연결이 필요하다고 알립니다.
- 연결 후에는 문서 유형, 조직, 작성자, 기간, 키워드로 범위를 좁혀 검색합니다.
- 권한 밖 문서 내용이나 누락된 첨부를 추정하지 않습니다.
- 답변에는 문서 ID·제목·버전·기준일 등 확인 가능한 원본 식별자를 남깁니다.
