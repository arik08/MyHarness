# POSCO Email MCP

`posco-email` MCP는 현재 사내 메일 연결을 위한 자리표시자입니다.

- 서버가 비활성 또는 도구가 없으면 메일 권한과 실제 연결이 필요하다고 알립니다.
- 연결 후에는 발신자·수신자·기간·제목·스레드 범위를 최소화해 조회합니다.
- 비공개 수신자나 삭제된 내용을 추정하지 않습니다.
- 답변에는 메시지 또는 스레드 식별자와 기준시각을 남기고 민감정보 노출을 최소화합니다.
