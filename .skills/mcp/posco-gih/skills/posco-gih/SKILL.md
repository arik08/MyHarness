# POSCO GIH MCP

`posco-gih` MCP는 현재 Global Information Hub 연결을 위한 자리표시자입니다.

- 서버가 비활성 또는 도구가 없으면 GIH 권한과 실제 연결이 필요하다고 알립니다.
- 연결 후에는 지역·시장·주제·자료 유형·기간으로 범위를 좁힙니다.
- 게시 상태와 최신 버전을 확인하고 미공개 자료를 추정하지 않습니다.
- 답변에는 자료 ID·제목·발행일과 기준시각을 남깁니다.
